# JeValery Vision - Уеб Сайт

## Описание
JeValery Vision е модерен уеб сайт за строителна компания, създаден с HTML, CSS и JavaScript. Сайтът предлага интуитивен интерфейс и богата функционалност за клиентите.

## Структура на проекта
```
jevalery-vision/
├── index.html              # Основен HTML файл
├── css/                    # Директория за CSS файлове
│   ├── style.css          # Основни стилове
│   ├── search.css         # Стилове за търсачката
│   └── language.css       # Стилове за езиковия селектор
├── js/                     # Директория за JavaScript файлове
│   ├── script.js          # Основен JavaScript
│   ├── search.js          # Функционалност на търсачката
│   └── language.js        # Функционалност на езиковия селектор
├── images/                 # Директория за изображения
│   ├── flags/             # Знамена за езиковия селектор
│   ├── home-slide-*.jpg   # Слайдове за началната страница
│   ├── project-*.jpg      # Изображения на проекти
│   └── service-*.png      # Икони за услуги
└── README.md              # Документация на проекта
```
